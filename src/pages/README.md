# 📁 pages/ — Website Screens / Views (ওয়েবসাইটের প্রধান পেজসমূহ)

এই ফোল্ডারে ওয়েবসাইটের প্রধান পূর্ণাঙ্গ পেজগুলো রয়েছে, যা নির্দিষ্ট ইউআরএল রুটে লোড হয়:

- **`Home.jsx`** (`/`): প্রধান ল্যান্ডিং পেজ।
- **`Login.jsx`** (`/login`): লগইন পেজ (Patient, Doctor ও Admin ট্যাব সহ)।
- **`Register.jsx`** (`/register`): সাইন আপ পেজ (Patient বা Doctor রেজিস্ট্রেশন)।
- **`DoctorList.jsx`** (`/doctors`): ডাক্তারদের তালিকা ও স্পেশালিটি ফিল্টার।
- **`DoctorProfile.jsx`** (`/doctors/:id`): ডাক্তারের প্রোফাইল ও বুকিং স্লট ক্যালেন্ডার।
- **`PatientDashboard.jsx`** (`/patient`): রোগীর ড্যাশবোর্ড (বুকিং, হিস্ট্রি ও প্রেসক্রিপশন ডাউনলোড)।
- **`DoctorDashboard.jsx`** (`/doctor`): ডাক্তারের কন্ট্রোল প্যানেল (অনুমোদন, শিডিউল ও লাইভ কিউ)।
- **`AdminDashboard.jsx`** (`/admin`): হসপিটাল অ্যাডমিন প্যানেল।
